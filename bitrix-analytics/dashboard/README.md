# Дашборд «Воронка по источникам»

Показывает, как сделки одного периода проходят воронку: сделки → вебинар → дозвон → квал → МС. Работает **только на вашем компьютере**: данные из выгрузки не отправляются в интернет.

## Что показывает

Атрибуция по **дате создания сделки**, срез по полю **«Источник»**:

| Показатель | Как считается |
|---|---|
| Новые сделки | Тип сделки «Новая» (галочка «Только новые сделки» можно снять) |
| Посмотрели вебинар / доходимость | Заполнена дата «Посетил вебинар»; доходимость = вебинар / сделки |
| Дозвонились | Заполнена «Дата диалога» **или** в «1/2/3 дозвон» стоит «Да» |
| Квалы | Заполнена «Дата квала» |
| МС назначено | Заполнена «Дата и время МС (квал)» |
| Квал → МС | Сделки, где есть и квал, и МС, делённые на сделки с квалом |

Фильтры: период (пресеты и свои даты), источники, только новые сделки. Все числа и графики пересчитываются сразу. Есть тёмная тема и таблица вместо любого графика.

## Запуск

1. Установите Python 3.9 или новее: https://www.python.org/downloads/ (на Windows отметьте «Add python.exe to PATH»). Больше ничего ставить не нужно.
2. Положите CSV-выгрузку сделок из Битрикс24 в папку `data` (если файлов несколько, берётся самый свежий).
3. Запустите `start.bat` (Windows) или `start.sh` (Mac/Linux). Откроется браузер на http://127.0.0.1:8765.
4. Новая выгрузка: замените файл в `data` и нажмите «Обновить данные» на странице.

Остановить: закройте окно или нажмите `Ctrl+C`.

## Приватность

- Адрес `127.0.0.1` доступен только на этом компьютере. Страница ничего не загружает из интернета, и браузеру это запрещает заголовок безопасности.
- Программа читает **только колонки из `settings.py`** (дата создания, источник, тип сделки, даты вебинара, диалога, квала, МС и флаги дозвона). Телефоны, почты, имена и комментарии в память не загружаются и в браузер не попадают.
- Файлы `*.csv`, `*.xlsx` и папка `data` исключены из git (`.gitignore`), случайно закоммитить выгрузку нельзя.
- Если что-то сломалось, присылайте текст ошибки, а не файл.

## Если у вас другие названия колонок или другое определение

Откройте `settings.py` в любом текстовом редакторе: там список колонок с комментариями. Например, чтобы «МС назначено» считалось по дате заявки, замените значение `mc` на `"Оставил заявку на МС"`. Если колонки не найдены, программа покажет на странице, каких именно.

## Дальше

Эта же страница будет получать данные не из файла, а из базы PostgreSQL, которую наполняет сборщик из Битрикс24 (папка `etl`). Расчёты в `static/metrics.js` от источника данных не зависят.

## Для разработки

```bash
python3 -m pip install pytest
python3 -m pytest              # загрузчик и сервер
node --test tests/metrics.test.js   # расчёт метрик
python3 tests/synth.py demo.csv     # выдуманная выгрузка для проверки внешнего вида
python3 server.py --file demo.csv
```
